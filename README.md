# Virasat-e-Sindh

An art project presenting the fading traditional crafts of Sindh: pottery, embroidery and mirror work, and leather work.

Presented by Mehak Lashari, Mehwish Badar and students.

## Add your photos

Create a folder named `images` next to `index.html` and put your pictures in it with these names:

- `pottery-1.jpg`
- `embroidery-1.jpg`
- `leather-1.jpg`
- `gallery-1.jpg` to `gallery-6.jpg`

Until a photo is added, the page shows a decorative placeholder. Tip: keep each photo under 500 KB so the site loads fast.

## Edit student names

Open `index.html`, find `id="students"`, and change the `<li>` names.

## Publish on GitHub Pages

1. Create a new repository on GitHub and upload all files (`index.html`, `style.css`, `script.js`, `images/`).
2. Go to **Settings > Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then Save.
4. After a minute your site will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
